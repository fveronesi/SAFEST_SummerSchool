# SAFEST SummerSchool

This repository hosts code and data shown at the SAFEST summer school in Pisa.

Data required for executing the Modelling Exercise can be download from my Dropbox:
https://www.dropbox.com/scl/fi/w31vutc0ty25b61bcha7o/ModellingExercise.7z?rlkey=4o61h659smua91fo8iaqmrrog&st=r1xj50xp&dl=0

This is a 7zip file that needs to be extracted in the folder ModellingExercise, where the .rmd is located.
Once extracted the folder ModellingExercise should have the following structure:
- ModellingExercise
  - Corine
  - DEM
  - ForestryData
  - ModellingArea
  - Results
  - Sentinel
